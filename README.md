# PilarBus – Aplicación de transporte público con seguimiento de colectivos en tiempo real.

## Descripción del proyecto

PilarBus es una aplicación móvil y plataforma web desarrollada en conjunto por la Municipalidad y la Universidad Nacional de Pilar. Su objetivo es permitir que los ciudadanos puedan consultar la ubicación de los colectivos en tiempo real, conocer sus recorridos y recibir alertas sobre desvíos o modificaciones del servicio.

## Control de versiones

El proyecto utilizará Git y GitHub para almacenar y controlar las diferentes versiones del código fuente.

Los integrantes trabajarán mediante ramas (*branches*) independientes para desarrollar nuevas funcionalidades o corregir errores.

Cuando un integrante finalice una tarea, deberá crear un Pull Request (PR) para solicitar la incorporación de sus cambios a la rama principal (main). Otro integrante revisará el código antes de aprobarlo.

## Integración y Entrega Continua (CI/CD)

Se utilizará GitHub Actions para automatizar el proceso de integración y entrega continua.

El proceso funcionará de la siguiente manera:

1. **Build:** se comprobará que el código pueda compilarse o construirse correctamente.
2. **Test:** se ejecutarán pruebas automáticas para detectar posibles errores.
3. **Deploy:** una vez aprobados los cambios y superadas las pruebas, se realizará el despliegue de la nueva versión en la nube.

Las validaciones de Build y Test se ejecutarán automáticamente al crear o actualizar un Pull Request. El Deploy se realizará después de integrar los cambios en la rama principal y superar las validaciones correspondientes.

## Beneficios

- Permite que varios desarrolladores trabajen al mismo tiempo.
- Facilita la detección y corrección de errores.
- Evita incorporar código sin revisar.
- Automatiza las pruebas y la validación del proyecto.
- Facilita la publicación de nuevas versiones de PilarBus.
- Ayuda a mantener la aplicación actualizada y disponible para los usuarios.
